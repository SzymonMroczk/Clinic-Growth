# Clinic Growth

Strona agencji Clinic Growth — skalowanie klinik medycyny turystycznej (Turcja, Albania) o pacjentów z zagranicy.

## Uruchomienie lokalnie

```bash
npm install
npm run dev
```

## Build na Cloudflare Pages

Framework preset: Astro

Build command:

```bash
npm run build
```

Build output directory:

```bash
dist
```

## Wysyłka na GitHub

Wrzuć cały folder do repozytorium, połącz repozytorium z Cloudflare Pages i ustaw build jak wyżej.
