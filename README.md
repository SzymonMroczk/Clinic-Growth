# Clinic Growth

Strona landing page dla agencji marketingowej obsługującej kliniki chirurgii estetycznej.

## Uruchomienie lokalnie

```bash
npm install
npm run dev
```

## Build na Cloudflare Pages

Framework preset: Astro

Build command:

```bash
npm run build
```

Build output directory:

```bash
dist
```

## Wysyłka na GitHub

Wrzuć cały folder do repozytorium, połącz repozytorium z Cloudflare Pages i ustaw build jak wyżej.
